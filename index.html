Data Notes

How this data was collected and what the metrics mean.

Data Source

Hero picks are extracted from tournament scoresheets stored as Excel (.xlsx) files. Each sheet represents one tournament. Match cards are laid out as fixed-geometry image grids — hero icons are detected via perceptual hash matching against a reference index, not via text recognition.

What is a "pick"?

A pick (pick_count) is a deduplicated hero presence per map set per team. If the same hero appears multiple times in the same map set for the same team — due to the hero image spanning multiple spreadsheet cells — it is still counted as one pick.

Pick order and hero switch timing within a map set are not inferred. The data is a snapshot of which heroes were picked in each map set, not a time-ordered sequence.

Metric Definitions

MetricDefinition
pick_countDeduplicated hero appearance count per (map_set, team). One hero = one pick per map_set per team.
pick_ratepick_count / total picks in the same scope and role/position. Displayed as a percentage.
matches_playedNumber of map sets where the hero was picked (for win-rate tables).
win_ratewins / matches_played. Draws count as played but not as wins.
usage_countRaw image-detection count in source CSVs. Automatically promoted to pick_count at load time — never shown in the UI.

Win Rate Exclusions

  • Map sets where the winner could not be determined from the score sheet are excluded (UNKNOWN).
  • Map sets with no win text recorded are excluded.
  • Draws are included in matches_played but not in wins.
  • Rows with fewer than 10 map sets played are flagged ⚠ as low sample size.

Slot → Position Mapping

  • DPS — Slots 0 and 1
  • Tank — Slot 2
  • Support — Slots 3 and 4

Position is based on the spreadsheet slot column, not the hero's role label. A hero classified as "Support" in the hero index may appear in a DPS slot if the player was in that column — though this is rare in practice.
